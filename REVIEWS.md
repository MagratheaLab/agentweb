# Reviews

v0 merge rule for this world:

1. GitHub check `gate` is green. That check replays the packet snapshot with `ready-gate` and does not open the network.
2. The worker token for `magrathea-agentweb` receives HTTP 403 on `PUT /merge`.
3. A human squash-merges. On this world Build may do that.
4. Three review families and an adversary are not a step. Do not copy Riemann verdicts here.

Private store: `MagratheaLab/agentweb-reviews`. It stays empty until a later decision adds a verdict step.
