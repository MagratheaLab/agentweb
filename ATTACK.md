# ATTACK map (living, via merged PRs only)

## Walls

1. A sentence about the whole web being ready
2. Rank, traffic, or model-citation counts as a result
3. A or AAAA used as identity
4. DNS judged from prose or from HTML
5. A live write to an origin without `world_claim: apply` and written consent

## DEAD_ENDS

- Scanning an open-ended domain list inside one packet
- Treating a redirect alone as a move
- Reusing `lemma`, `scout`, or `replicate` as this world's claim word
